# Kahiok!

Квизы в реальном времени, как Kahoot, только свои и бесплатные. Ведущий выводит вопросы на большой экран, игроки отвечают с телефонов по PIN-коду.

**Играть:** https://tatogart.github.io/Kahiok/

## Как играть

1. Ведущий открывает сайт → «Создать и провести игру» → выбирает квиз → «Провести».
2. На экране появляется PIN и QR-код.
3. Игроки открывают сайт на телефоне, вводят PIN и ник (или сканируют QR).
4. Ведущий жмёт «Начать». Пробел/Enter — следующий шаг.

## Что умеет

- Редактор квизов: викторина (2–4 ответа, можно несколько правильных), «Верно/Неверно», опрос без очков; время от 5 с до 2 мин; обычные, двойные или нулевые очки; картинки по ссылке или с устройства; перетаскивание вопросов.
- Очки как в оригинале: до 1000 за вопрос, чем быстрее, тем больше, плюс бонус за серию правильных ответов.
- Лобби с QR-кодом, реакциями игроков, удалением игроков и закрытием входа. Кнопка «Добавить бота», чтобы попробовать игру одному.
- Диаграмма ответов, анимированная таблица лидеров, пьедестал с барабанной дробью и конфетти.
- Вся музыка и звуки синтезируются в браузере, кнопка выключения в углу.
- Игрок может перезагрузить страницу или потерять связь и вернуться в игру со своими очками.
- Итоги в таблице и выгрузка в CSV. Импорт и экспорт квизов в JSON.

## Как это устроено

Это статический сайт без сервера и без сборки: HTML, CSS и ES-модули.

- Сеть: WebRTC через [PeerJS](https://peerjs.com/). Браузер ведущего хранит всё состояние игры, а публичный сигнальный сервер PeerJS нужен только чтобы игроки нашли ведущего по PIN.
- Квизы хранятся в `localStorage` браузера ведущего.
- Библиотеки лежат в `vendor/` (PeerJS — MIT, qrcode-generator — MIT, canvas-confetti — ISC).

```
index.html
css/style.css
js/main.js      — запуск, главная, навигация
js/library.js   — список квизов
js/editor.js    — редактор
js/host.js      — игра на экране ведущего
js/player.js    — игра на телефоне
js/net.js       — PeerJS
js/audio.js     — синтез музыки и эффектов
js/store.js     — хранение квизов
js/samples.js   — готовые квизы
```

## Запуск локально

```bash
npx http-server . -p 8080
```

Для отладки без интернета можно поднять свой PeerServer (`npx peer --port 9000`) и открыть
`http://localhost:8080/?peerhost=localhost&peerport=9000`.

## Публикация
